## Value Realized

### Code velocity
Power users are merging **3× more PRs** when using Agents / Cloud workflows vs. baseline.

### Developer time
Every agent session is equivalent to **~3 hours of developer time completed**.

### Quality at speed
**65% PR merge rate** — highest among tech vertical customers. We're increasing velocity **without sacrificing quality**.

### Output & ROI
Average developer is achieving **~3× output**. ROI is built around savings for these developers at scale across the active cohort.

**ROI framing (talk track):**  
~3× output × 4,392 active devs × 3 hrs saved per agent session → material recovered engineering capacity. The 65% merge rate supports an org-wide expansion case: faster delivery with quality intact.
