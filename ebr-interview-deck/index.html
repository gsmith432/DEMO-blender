EBR · Product Roadmap

What's next — Cursor product roadmap

Cloud Agents

Agents that run in the cloud

  • Isolated VMs with full dev environments — build, test, demo
  • Parallel agents; no local machine required
  • MCP, multi-repo, artifacts (screenshots, videos, PRs)
  • Trigger from IDE, web, Slack, GitHub, Linear, API

Uber fit: Async refactors across monorepo + microservices without blocking local dev.

Automations

Always-on agents

  • Schedule or event-triggered (PR, Slack, PagerDuty, webhooks)
  • Marketplace templates: bug find, vuln scan, daily digest
  • Memory + MCP for cross-run learning
  • Single-repo, multi-repo, or no-repo modes

Uber fit: PR triage, on-call incident → fix PR, weekly adoption reports to eng leads.

Bugbot

AI code review at scale

  • Auto-review on every PR; custom Bugbot Rules
  • 70%+ of flags resolved before merge
  • Autofix: spawns Cloud Agent to fix & push
  • Enterprise API for per-review analytics

Uber fit: Enforce service-mesh patterns; reduce review burden on 2,757 power users.

EBR · Demo

Demo: Automations with Cloud Agents

Live walkthrough — "Weekly PR quality automation for Uber Mobility Core"

Trigger: Every Monday 9am PT · GitHub PR merged to mobility-core

Automation flow:

  1. Cloud Agent clones repo, reviews last 7 days of merged PRs for regressions & pattern violations
  2. Runs targeted test suite in isolated VM; captures screenshot artifacts
  3. Posts summary to #mobility-eng Slack with top 3 findings + "Fix in Cursor" links
  4. If critical: opens draft PR with Autofix via Bugbot integration

Why this matters for Uber

Converts 10% cloud usage → daily async workflow. Champions (Marcus, Elena) can own the automation config. Measurable: PR defects caught, time-to-fix, eng hours saved.

90-day pilot proposal

Deploy in Mobility Core (1 squad) → expand to Marketplace → template for org-wide Automations library. ADM owns success metrics & champion enablement.
